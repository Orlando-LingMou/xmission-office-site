# Xmission Office · 产品介绍官网

> **秩序在眼前，专注成日常。**

本仓库承载 **Xmission Office（学习与办公版）** 的独立静态产品介绍网站，采用半透明毛玻璃（Liquid Glass）质感与静谧的日/夜间双主题设计，零外部 CDN 依赖，已直接部署至 GitHub Pages：

- **在线访问**：https://orlando-lingmou.github.io/xmission-office-site/

## 站点特性

- **零外部依赖**：Tailwind CSS v4 静态预编译输出至 `styles.css`，所有实机截图均为本地 WebP 优化资源，全球访问快速稳定。
- **日间 / 夜间双主题**：自动跟随系统偏好并支持顶部一键切换。
- **交互体验**：首屏可交互「Xmission Office 今日待办」毛玻璃体验卡（含即时 XP 进度与番茄钟计时）、滑动胶囊实机界面切换器、AI 一句话录入草稿演示、四套主题画廊与全屏毛玻璃灯箱。
